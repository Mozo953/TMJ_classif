1) Run segmentation only
------------------------
This command segments the images in `TMJ_clas` with UNet++ fold 2 and applies the post-processing:
fossa threshold 0.95 and top-2 connected components for condyle/fossa.

    python main_segmentation.py

Important for a fresh Git clone:
The segmentation launcher first looks for this trained checkpoint:

    TMJ_clas\unet_runs\unetpp_cv5_boundary_fossa_threshold\fold_02\best_tmj_unetpp_boundary_fossa_threshold.pt

If that checkpoint is not present, `python main_segmentation.py` now trains the UNet++ model automatically,
then runs inference. This is the default behavior so the project can be relaunched from Git without a
pre-existing checkpoint folder.

To force inference-only mode and require an existing checkpoint:

    python main_segmentation.py --no-train-if-missing

For a shorter smoke/debug run:

    python main_segmentation.py --train-folds 3 --train-epochs 5

To use another existing UNet++ run directory:

    python main_segmentation.py --seg-run-dir C:\path\to\unetpp_run

Default outputs:

    C:\Users\sadmin\Desktop\mozo\TMJ_clas\pred_all_images_fold02_fossa_erosion_top2_largest\masks
    C:\Users\sadmin\Desktop\mozo\TMJ_clas\pred_all_images_fold02_fossa_erosion_top2_largest\overlays


2) Run ResNet14 only, historical best pipeline
----------------------------------------------
This command uses the old 150-case post-processed segmentation masks by default:

    C:\Users\sadmin\Desktop\mozo\TMJ_clas\pred_fold02_fossa_erosion_top2_largest\masks

Command:

    python main_resnet14.py

If the historical mask folder is missing in a fresh clone, generate masks first:

    python main_resnet14.py --generate-masks-if-missing

If both masks and UNet++ segmentation checkpoints are missing, the same command still works:
`main_segmentation.py` is called internally and trains the segmentation checkpoint automatically.

Default output:

    C:\Users\sadmin\Desktop\mozo\best_models\reproduce_resnet14_old150

Historical ResNet14 reference performance:

    Accuracy          = 0.6867
    Balanced accuracy = 0.6544
    Macro F1          = 0.6255

Model input:

    one-hot segmentation mask, 3 x 160 x 160
    channel 0 = background
    channel 1 = condyle
    channel 2 = fossa


3) Run DINOv2
-------------
DINOv2 uses raw OPG images, not segmentation masks.
Preprocessing: aspect-ratio-preserving resize + padding to 512 x 512.

Command:

    python main_dinov2.py

If `TMJ_clas_old150_images_for_dinov3` is not present, the launcher falls back to `TMJ_clas`.
You can also pass a custom dataset:

    python main_dinov2.py --data-dir C:\path\to\dataset

Default output:

    C:\Users\sadmin\Desktop\mozo\code_classification\dinov2_tmd_experiment\outputs_dinov2_cv3_reproduce_old150

Historical DINOv2 reference performance:

    Accuracy          = 0.7467
    Balanced accuracy = 0.7389
    Macro F1          = 0.7407


4) Run the full RF + ResNet14 + blender pipeline
------------------------------------------------

then apply the validated weighted probability blender.

The default tracked CSV already contains both ResNet14 and RF probabilities. If the separate RF
OOF file is missing, the launcher reuses the RF columns inside:

    best_models\resnet14_plus_tabular_rf\resnet14_rf_blend_oof_predictions.csv

Output:

    C:\Users\sadmin\Desktop\mozo\outputs\main_complete_reference_blender\final_blender_predictions.csv

    Balanced accuracy = 0.7341
    Macro F1          = 0.7245

To retrain ResNet14 before applying the blender:

Note:
